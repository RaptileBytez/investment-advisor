**Value Investing** sucht nach Aktien, die unter ihrem inneren Wert
gehandelt werden — 1 € Unternehmensanteil für 0,70 € kaufen.

### Verwendete Signale

| Signal              | Bullish, wenn…                          |
| ------------------- | --------------------------------------- |
| Trailing-KGV        | niedrig (günstig auf Gewinnbasis)       |
| KBV                 | niedrig (günstig auf Buchwertbasis)     |
| Verschuldungsgrad   | niedrig (finanzielle Flexibilität)      |
| Dividendenrendite   | moderat hoch (3 – 6 %)                  |
| FCF-Rendite         | hoch (echte Cash-Erträge)               |

Jedes Signal trägt eine kleine Stimme bei; das Gesamtbild bestimmt das
Verdict.

### Warum es (historisch) funktioniert

- Günstige Bewertungen sind über Horizonte von 10+ Jahren *im Schnitt*
  zurück Richtung fair gelaufen — nicht jedes Quartal, nicht jeden
  Zyklus.
- Qualitäts-geprüftes Value (ohne „Value Traps") hat langfristig den
  breiten Markt geschlagen, allerdings mit höheren Drawdowns.

### Value Traps

Eine Aktie mit niedrigem KGV und hoher Dividendenrendite kann günstig
sein, *weil das Geschäft stirbt*. Warnzeichen:

- Anhaltend negative FCF-Wachstumsraten.
- Steigender Verschuldungsgrad.
- Branchenweiter Druck (Tabak, traditioneller Einzelhandel in einigen
  Märkten).

Dieser Berater kennzeichnet einige davon, aber nicht alle. Behandle das
Value-Verdict als Ausgangspunkt für eigene Recherche, nicht als
Stand-alone-Entscheidung.
