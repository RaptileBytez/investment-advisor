# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, **please do not
open a public issue.** Instead, email the maintainer privately:

📧 **raptile.bytez@gmail.com**

Include:

- A description of the issue and its impact.
- Steps to reproduce.
- Affected version / commit SHA.
- Your name and contact info if you'd like credit in the fix announcement.

You can expect an initial response within **7 days**. We aim to disclose
fixes responsibly: a patch first, public disclosure once users can upgrade.

## Scope

This project is in pre-MVP development and is intended for **personal use
only**. Once broker-API integration lands, the threat surface grows — at
that point this policy will be expanded with:

- API-key handling expectations.
- Audit-log requirements.
- Coordinated-disclosure timelines.

## Out of scope

- Issues in third-party data providers (e.g. Yahoo Finance) — report
  upstream.
- Risk-disclaimer / financial-advice concerns — see [README.md](README.md);
  this software is **not** financial advice.
